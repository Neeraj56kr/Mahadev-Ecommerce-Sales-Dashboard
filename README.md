# Mahadev-Ecommerce-Sales-Dashboard
 Interactive Power BI dashboard for analyzing E-Commerce sales performance, profit trends, customer insights, category analysis, and payment statistics using dynamic visualizations and filters.

## Features
- Sales Analysis
- Profit Analysis
- Quantity Tracking
- State & City Filters
- Quarterly Analysis
- Category-wise Insights
- Customer-wise Sales

## Tools Used
- Power BI
- DAX
- Data Visualization
